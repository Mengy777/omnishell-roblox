# Решения

## 2026-10-31 — Начальная структура

- Название: **OmniShell**, репозиторий: `omnishell-roblox`.
- Целевая среда первого этапа: локальный запуск в Roblox Studio.
- Исходники хранятся в текстовом виде и синхронизируются через Rojo. Генерируемые файлы мест не коммитятся.
- На первом этапе интерфейс создаётся средствами Roblox UI без внешних изображений и звуков.
- Каталог платформ отделён от кода экрана выбора.
- Никакая конкретная платформа пока не выбрана для полной реализации. Каталог Xbox пока не определяет поколение консоли.
- Публикация Roblox-места и загрузка сторонних игровых ресурсов не входят в текущий этап.
