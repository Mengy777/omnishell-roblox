# Состояние проекта

Обновлено: 2026-10-31.

## Реализовано

- Конфигурация Rojo и разделение клиентских, общих и серверных исходников.
- Каталог Windows XP/7/10/11, PlayStation 4/5 и Xbox.
- Экран выбора платформ с прокруткой.
- Информационный экран выбранной платформы и кнопка возврата.
- Документация, дорожная карта и правила продолжения работы.

## Проверки

- `default.project.json` успешно разобран как JSON.
- Rojo 7.7.1: `rojo build default.project.json -o build/OmniShell.rbxlx` — успешно.
- Luau 0.745: `luau-compile --null` — успешно для всех трёх исходных файлов. Это проверка синтаксиса и компиляции, не проверка Roblox API и типов в Studio.
- Проверка в Roblox Studio ещё не выполнена. Внешний вид и поведение нужно подтвердить нажатием Play.

## Ограничения

- Карточки открывают общий информационный экран прототипа, а не интерфейсы оригинальных систем.
- Загрузочные анимации, рабочие столы, игры и эмуляторы ещё не реализованы.
- Управление контроллером и внешний вид на разных разрешениях ещё не проверены.

## Следующее действие

Открыть прототип в Studio, проверить выбор всех карточек и возврат. Затем выбрать первую ОС или консоль и конкретную версию её интерфейса для реализации.
