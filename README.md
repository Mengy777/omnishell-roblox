# OmniShell

Модульный проект для Roblox Studio: выбор интерфейса операционной системы или консоли, загрузочный сценарий и общая библиотека игровых миров.

**Сейчас:** полноэкранный лаунчер с категориями Windows, консоли, macOS и «Другое». Карточка **Windows XP** открывает выбор профиля, затем рабочий стол Luna с окнами, «Пуском», панелью управления, Блокнотом, калькулятором и общей папкой игр. Остальные системы пока представлены информационными экранами. Персонаж в меню не создаётся.

Для XP подключены растровые элементы трёх схем Luna, стандартные обои, системные значки, 25 изображений пользователей и 35 WAV-файлов. Область реализованного поведения и ограничения описаны в [`docs/XP-COVERAGE.md`](docs/XP-COVERAGE.md). Пиксельная идентичность всех экранов и работа в Studio ещё не подтверждены.

**Устройство проекта:** каждая ОС или консоль — отдельная оболочка одной библиотеки. Игровой режим реализуется один раз, а оболочки меняют его оформление запуска и навигацию. Все оболочки будут предоставлять доступ к одному набору реализованных игр.

## Запуск в Roblox Studio

Нужны Roblox Studio, CLI [Rojo](https://rojo.space/) и плагин Rojo для Studio.

1. Клонировать репозиторий и открыть его папку в терминале.
2. Запустить `rojo serve default.project.json`.
3. Открыть новое место в Studio и подключить плагин Rojo к серверу по адресу, который покажет CLI.
4. Синхронизировать проект и нажать **Play**. Экран выбора появится у игрока.

Для сборки файла места: создать папку `build`, затем выполнить `rojo build default.project.json -o build/OmniShell.rbxlx` и открыть полученный файл в Studio.

Проект предназначен для запуска из Studio; публикация места не требуется для первого прототипа.

## Постоянная папка сборок

По просьбе владельца текущая сборка хранится в **`D:\Omni-Shell\OmniShell.rbxlx`**. Открывать этот файл в Studio и нажимать Play. После обновления файла на диске уже открытое место нужно переоткрыть, чтобы загрузить новую версию.

Обновление из PowerShell в папке репозитория: `./scripts/build.ps1`. Скрипт сначала собирает и проверяет XML места, затем сохраняет копию в `D:\Omni-Shell\builds` и обновляет постоянный файл. Если Rojo не установлен в PATH, можно передать `-RojoPath 'путь\к\rojo.exe'`. Папка назначения меняется через `-OutputDirectory`.

Сборка также копирует ресурсы XP в `D:\Omni-Shell\assets\xp` и локальную подпапку `content/omnishell/xp` установленного Studio. После обновления Studio повторить сборку или `./scripts/sync-xp-assets.ps1`. Один файл `.rbxlx` без этих ресурсов не включает обои, значки, звуки и локальные шрифты XP.

Исходники остаются в репозитории; папка на диске D содержит сборки для запуска.

## Фоновые проверки

`python tests/check.py` компилирует Luau и исполняет проверки на имитации сервисов Roblox, не открывая окна. Для Luau CLI можно передать `--luau` и `--compiler`. Параметр `--api` принимает API dump Studio для проверки имён свойств. Проверка не заменяет Play, прослушивание звуков и сравнение снимков экрана в настоящем Studio.

## Файлы проекта

| Путь | Назначение |
| --- | --- |
| `src/client/` | Экран выбора и клиентская навигация |
| `src/shared/` | Каталог платформ и общие модули |
| `src/server/` | Серверная часть будущих игровых режимов |
| `assets/` | Исходные ресурсы и сведения об их происхождении |
| `docs/STATUS.md` | Что сделано, проверено и что делать дальше |
| `docs/ROADMAP.md` | Этапы развития |
| `docs/DECISIONS.md` | Принятые технические решения |
| `AGENTS.md` | Правила работы для следующих сессий |

Пока не выбрана лицензия, репозиторий не предоставляет отдельного разрешения на использование чужих материалов. Добавлять игровые ресурсы нужно с учётом прав на конкретные материалы.
