# Решения

## 2026-10-31 — Начальная структура

- Название: **OmniShell**, репозиторий: `omnishell-roblox`.
- Целевая среда первого этапа: локальный запуск в Roblox Studio.
- Исходники хранятся в текстовом виде и синхронизируются через Rojo. Генерируемые файлы мест не коммитятся.
- На первом этапе интерфейс создаётся средствами Roblox UI без внешних изображений и звуков.
- Каталог платформ отделён от кода экрана выбора.
- Никакая конкретная платформа пока не выбрана для полной реализации. Каталог Xbox пока не определяет поколение консоли.
- Публикация Roblox-места и загрузка сторонних игровых ресурсов не входят в текущий этап.

## 2026-10-31 — Общие игры, разные оболочки

- По пожеланию владельца все ОС и консоли становятся разными интерфейсами одной библиотеки. Код игр не копируется для каждой платформы.
- Категории верхнего уровня: Windows, консоли, macOS и «Другое». Конкретная версия macOS пока не выбрана; раздел «Другое» пока пуст.
- `src/shared/Games.luau` — единственный каталог реально доступных игр. Пока он пуст; коммерческие названия не выдаются за готовые порты.
- Для лаунчера отключён `Players.CharacterAutoLoads`. В пустом месте автоматическое появление персонажа вызывало падение и повторные смерти. Камера меню статична, игровые HUD скрыты.
- Будущая игровая сессия должна явно загрузить персонажа в безопасной сцене, восстановить нужные HUD и камеру, а при возврате убрать персонажа. Этот жизненный цикл реализуется вместе с первой игрой.
- UI занимает весь игровой viewport; на узких окнах боковая навигация превращается в верхние вкладки, число колонок карточек меняется автоматически.

## 2026-10-31 — Постоянная папка сборок

- Владелец выбрал диск D для сборок. Постоянный путь: `D:\Omni-Shell\OmniShell.rbxlx`.
- `scripts/build.ps1` обновляет этот файл после успешной сборки Rojo и разбора XML; отдельные версии сохраняются в `D:\Omni-Shell\builds` с временной меткой UTC.
- Репозиторий исходников остаётся на прежнем месте. Окна Studio для обновления файлов не активируются.
