# Windows XP: покрытие текущей реализации

Цель владельца — точное воспроизведение интерфейсов XP, профилей и звуков без этапа установки ОС. Текущий код — нативная оболочка Roblox, а не запуск бинарных файлов Windows. Ниже зафиксировано фактическое покрытие; полного соответствия всех экранов XP эта версия пока не достигает.

## Реализованные переходы

Карточка Windows XP → экран приветствия → профиль → рабочий стол. Из «Пуска» доступны программы, параметры, смена пользователя и выключение с возвратом в OmniShell. Изображения пользователей и названия профилей отражаются на экране входа и в «Пуске».

## Ресурсы

- Схемы Luna Blue, Olive и Silver: заголовки окон, кнопки, флажки, «Пуск», панель задач и область уведомлений используют растровые ресурсы из коллекции XP.
- 20 фоновых рисунков и отсутствие рисунка; источник BMP Bliss сохранён, для показа используется PNG без изменения изображения.
- 25 стандартных картинок учетных записей.
- 35 WAV-файлов из набора XP. К входу, выходу, выключению, ошибкам, меню, сворачиванию и восстановлению подключены соответствующие события. Само наличие остальных файлов не означает, что все события XP уже реализованы.
- По прямому пожеланию владельца используется только стандартный курсор Roblox. Курсор XP, его тень и след полностью удалены.
- Tahoma, Trebuchet MS и Lucida Console берутся из локальной Windows при сборке.
- Источники и сведения о правах: `assets/xp/SOURCES.md`.

| Пользователи | Создание, переименование, выбор изображения, удаление неактивного пользователя и переключение профилей |

| Панель задач | Часы, быстрая панель, автоскрытие, переключение обычного и классического меню «Пуск» |
| Звук | Индивидуальные громкость/выключение звука, проверка выбранного звука и звуки основных действий |
| Мышь | Интервал двойного щелчка; указатель остаётся стандартным Roblox |

| Заставка | Пустой экран или бегущая строка, предпросмотр, ожидание и выход по вводу |

## Что пока не реализовано или не подтверждено

- Полная пиксельная геометрия всех экранов, все апплеты панели управления и все стандартные приложения XP. Ряд диалогов адаптирован и должен быть сверён с оригиналом.
- Панель управления, вкладки оборудования/расширенных свойств и некоторые меню покрыты частично. Недоступные команды приложений отображаются неактивными.
- Пароли и реальная модель прав Windows, установка программ, службы, драйверы, файловая система исходной Windows, Интернет Explorer и сетевой стек Windows.
- Постоянное хранение профилей и файлов между остановками Play. Текущее состояние сохраняется при переключении оболочек и пользователей внутри одного запуска клиента. После остановки Studio Play оно сбрасывается.
- Флаги закрепления панели задач и группировки кнопок сохраняются в профиле; самостоятельное перетаскивание панели и группировка окон ещё не реализованы.
- Размер системного шрифта пока меняет подписи значков; масштабирование всех метрик XP не реализовано. Цветопередача не переключается на 16 бит.
- Локальное оборудование, системная громкость, настройки Windows и файлы вне оболочки не меняются.
- Воспроизведение звуков, загрузка локальных шрифтов, поведение фокуса и визуальный результат пока не проверены через Play. Не утверждать обратного на основании фоновых проверок.

## Проверки

`python tests/check.py` проверяет компиляцию 11 файлов, учетные записи, вход, 22 вкладки параметров, применение обоев, изоляцию настроек профилей, сохранение/повторное открытие текста, арифметику, пять расположений Проводника, команды запуска, смену пользователя, очистку оболочки и отсутствие автоспавна. Проверяется наличие ресурсов каталогов и декодирование WAV. При наличии API dump сверяются имена присваиваемых свойств.

Сервисы Roblox в тесте имитируются. В настоящем Studio всё ещё нужны проверка Play, прослушивание звуков и сравнение одинаковых экранов с референсами XP при одинаковом разрешении.
