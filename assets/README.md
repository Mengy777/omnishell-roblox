# Ресурсы

В начальном прототипе внешних ресурсов нет.

Для добавленных изображений, звуков, моделей и шрифтов записывать источник, автора, условия использования и Roblox asset ID, если он есть. Большие бинарные файлы и игровые архивы сначала обсудить отдельно; эту папку использовать для отобранных исходных ресурсов проекта.
